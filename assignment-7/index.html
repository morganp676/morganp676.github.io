[1] 40.92308
sd(df$chirps)
[1] 5.589597
cor(df$temp, df$chirps)
[1] 0.970876

Slope: m = r(sy/sx)

Intercept: b = \(\bar{y}\) - m\(\bar{x}\)

m = 0.97(4.11/5.58) = 0.714

b = 75.69 - 0.714(40.92) = 46.47

Thus, temp = 0.714(chirps) + 46.47.
